## Prompt

Saya adalah mahasiswa yang sedang mengerjakan tugas proyek pengembangan aplikasi mobile menggunakan Flutter, yaitu aplikasi pemantau kualitas udara bernama Lumair (SDG 11: Sustainable Cities and Communities, pendekatan Smart City). Pada tahap ini saya kembali memperbaiki halaman Prakiraan 24 Jam, kali ini dari sisi layout responsif: saat perangkat di-rotate ke landscape, tampilan harus berubah menjadi dashboard dua kolom bergaya aplikasi pemantau udara modern (referensi IQAir/AirVisual) — kolom kiri memuat banner insight dan kartu grafik "Tren AQI 24 jam ke depan", sedangkan kolom kanan memuat kartu "Ringkasan 4 hari" (4 kartu harian berjajar) dan kartu "Per jam, 24 jam ke depan" berisi daftar bar konsentrasi PM2.5 dalam µg/m³ yang memuat seluruh 24 jam (jam di kiri, bar di tengah, angka di kanan, lalu badge kategori AQI berbentuk pil dengan warna kategori). Tampilan portrait tetap seperti sebelumnya sehingga pengguna tidak kehilangan informasi apa pun saat me-rotate. Saya butuh roles UI/UX Designer sekaligus Flutter Developer untuk menata ulang _responsif layout_ dengan tetap memakai komponen widget yang sama di kedua orientasi agar identitas visual (tema gelap premium, kartu kaca/glassmorphism, warna kategori AQI konsisten) tidak berganti-ganti. Grafik tetap harus memenuhi standar revisi sebelumnya: skala sumbu Y mengikuti rentang data dengan interval bilangan bulat, label sumbu X pada kadar jarak seragam, dan garis bantu putus-putus tetap dipertahankan; navigasi bawah 5 menu tetap ada; kartu info edukasi tetap tersedia dalam kedua orientasi. Pastikan kode menggunakan null safety, clean code, responsif untuk semua ukuran layar, tidak memakai package deprecated, dan mudah dipahami mahasiswa; sertakan juga dokumentasi prompt/context/constraint dan evaluasi hasil untuk laporan.

## Context

Halaman Prakiraan 24 Jam sudah memiliki: banner insight (tren + jam terbaik/terburuk + saran aksi), kartu grafik interaktif AQI 24 jam (tooltip sentuh, garis ambang, legend warna kategori), kartu info edukasi buka-tutup "Cara membaca halaman ini (AQI & PM2.5)", ringkasan 4 hari, chips per jam, dan daftar bar PM2.5 — semuanya memakai type scale & spacing token dari revisi sebelumnya. Revisi ini menyikapi keungan informasi saat landscape: layout satu kolom memaksa pengguna menggulir jauh dan kartu harian kecil membuat contenedor informasi terpecah. Kartu harian kini juga menampilkan rentang ambang kategori "(50–100)" sehingga warga tahu apakah nilai AQI masih jauh dari batas alias nyaris naik kategori, dan alasan cara membaca grafik tetap tersedia. Data tetap dari API Open-Meteo Air Quality gratis tanpa API key; hasil dipublikasikan sebagai versi web melalui GitHub Pages agar mudah diuji dan dinilai.

## Constraint

Layout harus berubah otomatis saat rotasi: deteksi orientasi melalui MediaQuery di dalam screen, tanpa membuat halaman baru — satu Widget sama melalui dua body (portrait satu kolom; landscape dua kolom kiri 57% : kanan 43%). Komponen section wajib diekstraksi menjadi widget bersama (__InsightBanner_, _ChartCard_, _DayCardsSection_, _HourChipsSection_, _PmListSection_) alias screenshot refresm harus ada konsistensi visual antar orientasi, bukan desain ganda yang berbeda-beda; hanya jarak antar kolom dan tinggi chart yang boleh beda (chart landscape 300, portrait 240). Landscape menghapus chips per jam agar tidak ada informasi ganda — daftar PM2.5 24 jam menggantikannya; portrait tetap menampilkan chips. Baris PM2.5 wajib pakai badge pill kategori (radius 999, warna kategori dengan isi alpha 0.12 dan border alpha 0.5) — konsisten dengan chips. Kartu harian wajib menampilkan rentang ambang (0–50, 51–100, 101–150, 151–200, 201–300, 301–500). Kartu info edukasi di landscape tetap full-width di atas kedua kolom. Type scale & spacing token dari revisi sebelumnya wajib dipakai — tidak ada lagi ukuran teks atau jarak acak. Error/loading state dan tombol "Coba lagi" tetap harus berlaku di kedua orientasi. Layout dua kolom harus tetap dapat digulir secara independen (dua ListView) sehingga konten kanan panjang (24 bar) tidak menggulir seluruh halaman. Struktur file tetap hanya menyangkut lib/presentation/screens/forecast_screen.dart, tanpa menyentuh halaman app lainnya. Verifikasi wajib: `flutter analyze` tanpa issue, seluruh test lulus, build web sukses untuk GitHub Pages.

## Evaluasi hasil

- Layout responsif terverifikasi: body memakai dua kelas (`_PortraitBody`, `_LandscapeBody`) serupa struktur referensi — kiri (banner insight, kartu "Tren AQI 24 jam ke depan", footer skala) dan kanan (kartu "Ringkasan 4 hari" 4 kartu harian sejajar, kartu "Per jam, 24 jam ke depan" + 24 bar PM2.5).
- Grafik di landscape memakai tinggi 300 (asi tens, tidak ['flat']), skala Y tetap mengikuti data dan label X tetap seragam — standar revisi sebelumnya dipertahankan.
- Baris PM2.5 kini memakai badge pill kategori (radius 999) dengan warna kategori AQI — konsisten dengan chips dan legenda; angka µg/m³ diberi lebar kolom cukup (72) dan badge tidak menggunakan terminal teks lebar tak_past.
- Kartu harian menampilkan rentang ambang "(50–100)" di bawah kategori (berlaku di kedua orientasi — sesuai keputusan soal konsistensi).
- Kartu edukasi tetap full-width di atas kolom landscape dan di posisi semula di portrait; telusur informasinya tidak hilang saat rotasi.
- Chips per jam dihilangkan di landscape (digest mencegah informasi ganda dengan daftar 24 bar) dan tetap dipakai di portrait.
- Verifikasi otomatis lulus: `flutter analyze` 0 issue, seluruh 11 unit/widget test lulus, `flutter build web --release` sukses untuk GitHub Pages.
- Golden Rules tetap terجامikan saat rotasi: (1) konsistensi — satu set widget yang sama di kedua orientasi; (3) subset viewer statistik galaman tetap bekerja; (5) error recovery tetap ada; (8) info legend + tooltip langsung aksesibel, tidak perlu berpindah konteks untuk memahami nilai.
